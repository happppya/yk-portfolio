# How to Git

## How to see status

git status

## Push new changes

Add all the changes for the current commit
git add .

Save the new commit (version) with a description
git commit -m "put here what you changed"

Push the new changes
git push

## Receive new changes

Pull the new data
git fetch

Check if you are behind in commits
git status

Pull all the new changes to local version
git pull
